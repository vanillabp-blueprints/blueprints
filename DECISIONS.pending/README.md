# Decisions of the branch being merged

This repository keeps no decision log. A decision is written down where it applies: a rule in
`CONTRIBUTING.md`, a choice of one blueprint in its `README.md` or `AGENTS.md`.

A file here makes a decision of a branch easy to see in the review of that branch. It lives
until the next merge and is then deleted. Nothing cites it. Before you delete it, check that
what it decided is in one of the files above.
